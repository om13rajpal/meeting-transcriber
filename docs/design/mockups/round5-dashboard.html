Dashboard

The authenticated home screen, at production fidelity. Same tokens as the landing page, applied quietly: no stamps, no redaction, nothing above 30px, nothing slower than 400ms. Every state below is live. Tick a checkbox, type in a search box, press Delete, open the avatar menu.

What changed since the Round 2 rough

  • The bulk bar stopped being yellow. Highlighter yellow is the search mark and the Transcribing status, nothing else. The bar is now a neutral raised surface and the selected count carries the weight in mono.
  • The money is right. Round 2 showed a 26 minute meeting at $0.0187, which is roughly two and a half minutes of Nova-3. Every cost on this screen is duration times $0.0071 per minute, formatted the way formatCost actually formats it, and the estimated ones say so.
  • Failed rows say what failed. A status pill alone tells you nothing you can act on, so the row now carries the real errorMessage next to it, and the upload queue above shows the same job that produced it.
  • Three uploads at once, because that is what the code does. handleTranscribeAll fires every pending file concurrently, so the queue shows one climbing, one handed off, one broken, each with its own Cancel or Retry.
  • Every state is drawn, not described. First run, loading, and no results were placeholders before. The skeleton is now the row layout itself rather than two grey slabs, and the first run screen speaks this product's language instead of "no data".
  • Two lines of chrome removed. No spinner anywhere, no card shadows, no second border weight. The list is hairlines and space, and the only line heavier than 1px on the whole screen is the focus ring.
